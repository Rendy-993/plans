ЯК ЦЕ ПРАЦЮЄ

Додати власні страви

  1. Розмісти файл dishes.json поруч з іншими файлами сайту.
  2. Скопіюй структуру з dishes.example.json і заміни приклади власними стравами.
  3. Вкажи категорію: breakfast, lunch, dinner або salad.
  4. Відкрий сайт через локальний сервер, наприклад розширення Live Server у VS Code.

План харчування зберігається в цьому браузері на цьому пристрої. Щоб перенести його на інший пристрій, потрібно окремо перенести дані браузера або додати серверне зберігання.
